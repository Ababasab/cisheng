# 词声 · 拍照听单词

面向手机和电脑的轻量网页。选择图片或手机拍照 → 浏览器本地中英文混排 OCR → 校对 → 去重保存 → 默认 A–Z 排序 → 点按逐词朗读。

支持美式 / 英式、语速、短语、手动增删改、搜索、原始顺序、TXT 导出。未登录词库按浏览器与网站域名隔离；启用云同步后，同一邮箱账号可在多设备同步单词和文件夹。不要只依赖浏览器保存，定期导出备份。

## 文件夹与归档

左侧“单词文件夹”支持新建、自定义名称（最多 60 字）、重命名、归档与恢复。第一次打开新版时，原有词汇自动归入“默认单词本”，保留原单词 ID、口音、语速和中文隐藏状态。仍保存在原来的 `word-notes-v1` 存储键中，结构版本为 2。

每次手动输入、示例导入或图片识别后的校对窗口，都可选择添加到已有文件夹，或填写新文件夹名称并添加。默认追加到当前文件夹；取消操作不会创建空文件夹。仅在目标文件夹内去重，同一个词可以放在多个文件夹中。切换文件夹会清空搜索条件并收起之前的例句。

归档保留全部词汇，在“已归档”中仍可打开、学习、朗读和导出；恢复后可继续编辑与追加。归档文件夹不出现在添加目标中。重命名要求名称不为空且不与已有名称重复，归档文件夹也参与重名检查。

搜索、排序、计数、TXT 导出与清空都只针对当前文件夹。清空仍需在页面确认，只影响当前文件夹；其他文件夹及归档词汇不受影响。所有文件夹归档后可直接新建，不会自动生成空单词本。刷新保留文件夹、归档和当前选择；登录后同步单词与文件夹，当前选择仍按设备保留。

## 中文、音标与随机例句

单词旁自动加载中文释义与参考音标，支持逐词或一键隐藏全部中文；隐藏状态保存在原有存储结构中，不会清空旧单词。隐藏某个词的中文也会隐藏其例句译文。音标来自 ECDICT，以英式为主；单词及整句朗读遵循所选美式/英式和语速。

词典为本站静态资源，共 758,516 个词条，常用 36,890 个词条优先加载，其他按前两个字母分片加载。词典未收录和网络加载失败分别提示，不会编造释义或音标。

“生成例句”仅在点击时随机抽取 2 条双语例句，再次点击尽量避开上一组；例句池有限，耗尽后可能重复。例句来自 Tatoeba 社区以及词声编写的 147 条学习例句。110 个常用种子词/短语均有至少 3 条，其他词可通过公开 Tatoeba API 查询母语者贡献、直接中文翻译和适合学习长度的完整句子；仍可能存在语境和社区资料错误。无结果或连接失败会如实提示，支持重试，不用通用模板凑句。不是运行时 AI 创作，无需 AI 账户或密钥。

例句不自动展开、不自动朗读。每句提供整句朗读按钮，中文隐藏状态跟随所属单词。常用词的例句随站点缓存；其他词只在点击时把当前词发往 Tatoeba，不发送照片及整本单词列表。来源、作者、许可和原句/译文链接在页面和 `dist/sources.html` 中提供，ECDICT MIT 许可证随站点保留。

重新准备数据：`python scripts/build_learning_data.py` 和 `python scripts/cache_examples.py`；原始下载缓存位于被 Git 忽略的 `data-cache/`。例句接口存在网络和服务可用性限制，构建时缓存可避免高频查询。

## 本地运行

在此目录执行 `python -m http.server 4173 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:4173。请通过 HTTP/HTTPS 打开，直接双击 HTML 无法加载模块与 OCR worker。

OCR 引擎与中英文模型已放在 `dist/vendor/`，运行时不依赖外部 CDN，也不上传照片。识别适合清晰印刷体，结果仍需校对。PDF 可从“导入词表文件”导入；HEIC 请先转为 JPG。

### 单词书识别优化

默认自动分栏，按从左到右、每栏从上到下的顺序识别。小图最多放大两倍，最长边限制为 3200 像素。旧词首模式仍检测序号后的空白以减少页角干扰。

默认“自动识别单词／短语”，同时装载英语与简体中文模型，按 TSV 行位置和置信度提取英文词条，在中文、音标、词性前结束，保留短语、省略号、sb/sth 与 healthy/fit 等斜杠写法。自动寻找 1–4 栏的持续空白，忽略页首大标题，去除长表格线；检测到主要彩色印刷时增加颜色对照识别，只修复低置信度且不截短的词条。稀疏或复杂布局结果太少时再用稀疏文字模式重试。支持单栏、双栏、三栏手动覆盖，以及旧词首/全部英文模式。扫描 PDF 也采用混排模型和多栏提取。

此版本用用户三栏彩色短语原图逐行核对 89 行，保存时去重为 88 项；另测试了黑白单/双/三/四栏、蓝色带表格线词表。不是任意照片、手写、严重倾斜或模糊图片都能完全准确，仍需校对。不调用云端 AI，不需要 OpenAI 账户。首次自动识别下载约 4.5 MB 模型，额外加载本地识别引擎。中文模型来源、固定版本和许可证见 dist/vendor/lang/SOURCES.md。

验证：`node --test tests/*.test.js`；`QA_URL` 指定站点后运行 `python tests/ocr_layout_browser_qa.py [三栏短语原图路径]`。

发音使用设备的 Web Speech API，默认 en-US，可切换 en-GB；优先选择对应口音的本机声音，失败时尝试其他对应口音声音，最后以指定 lang 尝试浏览器默认声音（实际口音由浏览器决定）。声音列表尚未加载时也可尝试默认声音。系统语音实现可能联网，实际音质由设备决定。微信内置浏览器不支持时，请用系统浏览器打开。浏览器自动化只验证朗读参数，实际声音需在用户设备试听。

## 手机 OCR 加载修复

首次识别需要从本站下载模型与引擎，不是初次打开就已完全离线。新增 LSTM-only 英语模型 eng-lstm-v1.traineddata.gz（2,952,873 字节），替代初始化时下载的旧 10,923,060 字节模型；旧文件仅保留兼容，不再被新识别流程请求。重下模型可运行 python scripts/download_ocr_model.py，来源为固定版本 @tesseract.js-data/eng 1.0.0 的 4.0.0_best_int。

初始化显示模型下载字节数和引擎/内存/模型装载阶段。识别线程在初始化前就归应用管理，取消立即终止下载和 worker；下载最长 120 秒，每个 worker 阶段最长 90 秒，失败后恢复上传并保留具体提示。直接将下载模型传入 worker，避开部分手机 IndexedDB 缓存卡住的问题。模型仍利用浏览器普通 HTTP 缓存，不依赖第三方运行时 CDN。适配层 dist/ocr.js 使用随站点固定的 Tesseract.js 6.0.1 worker 消息协议，升级供应商版本时必须重新验证协议和 OCR 测试。

验证：node --test tests/*.test.js；python tests/ocr_mobile_qa.py；python tests/browser_qa.py；tests/book_qa.py 需要原图和参考词表路径。手机视口测试不等同于真实 iPhone 网络；不能保证 GitHub Pages 在所有移动网络可达。
