# 词声 · 拍照听单词

面向手机和电脑的轻量网页。选择图片或手机拍照 → 浏览器本地英文 OCR → 校对 → 去重保存 → 默认 A–Z 排序 → 点按逐词朗读。

支持美式 / 英式、语速、短语、手动增删改、搜索、原始顺序、TXT 导出。本地存储按浏览器与网站域名隔离，不跨设备同步。不要只依赖浏览器保存，定期导出备份。

## 文件夹与归档

左侧“单词文件夹”支持新建、自定义名称（最多 60 字）、重命名、归档与恢复。第一次打开新版时，原有词汇自动归入“默认单词本”，保留原单词 ID、口音、语速和中文隐藏状态。仍保存在原来的 `word-notes-v1` 存储键中，结构版本为 2。

每次手动输入、示例导入或图片识别后的校对窗口，都可选择添加到已有文件夹，或填写新文件夹名称并添加。默认追加到当前文件夹；取消操作不会创建空文件夹。仅在目标文件夹内去重，同一个词可以放在多个文件夹中。切换文件夹会清空搜索条件并收起之前的例句。

归档保留全部词汇，在“已归档”中仍可打开、学习、朗读和导出；恢复后可继续编辑与追加。归档文件夹不出现在添加目标中。重命名要求名称不为空且不与已有名称重复，归档文件夹也参与重名检查。

搜索、排序、计数、TXT 导出与清空都只针对当前文件夹。清空仍需在页面确认，只影响当前文件夹；其他文件夹及归档词汇不受影响。所有文件夹归档后可直接新建，不会自动生成空单词本。刷新保留文件夹、归档和当前选择；不跨设备同步。

## 中文、音标与随机例句

单词旁自动加载中文释义与参考音标，支持逐词或一键隐藏全部中文；隐藏状态保存在原有存储结构中，不会清空旧单词。隐藏某个词的中文也会隐藏其例句译文。音标来自 ECDICT，以英式为主；单词及整句朗读遵循所选美式/英式和语速。

词典为本站静态资源，共 758,516 个词条，常用 36,890 个词条优先加载，其他按前两个字母分片加载。词典未收录和网络加载失败分别提示，不会编造释义或音标。

“生成例句”仅在点击时随机抽取 2 条双语例句，再次点击尽量避开上一组；例句池有限，耗尽后可能重复。例句来自 Tatoeba 社区以及词声编写的 147 条学习例句。110 个常用种子词/短语均有至少 3 条，其他词可通过公开 Tatoeba API 查询母语者贡献、直接中文翻译和适合学习长度的完整句子；仍可能存在语境和社区资料错误。无结果或连接失败会如实提示，支持重试，不用通用模板凑句。不是运行时 AI 创作，无需 AI 账户或密钥。

例句不自动展开、不自动朗读。每句提供整句朗读按钮，中文隐藏状态跟随所属单词。常用词的例句随站点缓存；其他词只在点击时把当前词发往 Tatoeba，不发送照片及整本单词列表。来源、作者、许可和原句/译文链接在页面和 `dist/sources.html` 中提供，ECDICT MIT 许可证随站点保留。

重新准备数据：`python scripts/build_learning_data.py` 和 `python scripts/cache_examples.py`；原始下载缓存位于被 Git 忽略的 `data-cache/`。例句接口存在网络和服务可用性限制，构建时缓存可避免高频查询。

## 本地运行

在此目录执行 `python -m http.server 4173 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:4173。请通过 HTTP/HTTPS 打开，直接双击 HTML 无法加载模块与 OCR worker。

OCR 引擎与英语模型已放在 `dist/vendor/`，运行时不依赖外部 CDN，也不上传照片。模型首次加载约 11 MB，手机首次识别需要等待。识别适合清晰印刷体；手写、中文混排和音标可能产生多余词，必须校对。英文短语可能被拆为单词，可在校对框合并为一行。不支持 PDF 和 HEIC 直接识别。

### 单词书识别优化

默认自动检测中间栏缝，左右两栏分别识别，保留左栏在前、右栏在后的阅读顺序。可手动选择单栏或双栏。小图最多放大两倍，最长边限制为 3200 像素；检测序号和词条之间的空白，排除序号列及页角装饰的干扰。

默认“每行开头的词条”只提取每行的第一个英文词，避免将中文释义误识别出的字母、考频和词性加入单词本。一行有多个单词时切换“全部英文”；短语仍可在校对框合并。清晰的双栏印刷词书比原版识别更好，不代表任意照片或手写都能完全准确。不调用云端 AI，不需要 OpenAI API 账户和密钥。

发音使用设备的 Web Speech API，默认 en-US，可切换 en-GB；优先选择对应口音的本机声音，失败时尝试其他对应口音声音，最后以指定 lang 尝试浏览器默认声音（实际口音由浏览器决定）。声音列表尚未加载时也可尝试默认声音。系统语音实现可能联网，实际音质由设备决定。微信内置浏览器不支持时，请用系统浏览器打开。浏览器自动化只验证朗读参数，实际声音需在用户设备试听。

## 验证

- `node --test tests/words.test.js tests/learning.test.js tests/folders.test.js`
- `node --check dist/app.js`
- `python tests/browser_qa.py`（需要 Python 的 pillow、playwright，以及已安装的 Chrome）
- `python tests/learning_browser_qa.py`：真实词典、按需例句、隐藏与持久化、口音/语速参数、手机排版。
- `python tests/folders_browser_qa.py`：旧数据迁移、指定目标追加/新建、文件夹隔离、命名与重名、归档/恢复、导出/清空范围、取消、全部归档后的刷新和手机排版。

依赖：Tesseract.js 6.0.1、tesseract.js-core 6.0.0、英语 traineddata。随包保留 Apache 2.0 许可证。重新下载依赖可执行 `python download_ocr.py`。

参考：[Tesseract.js 本地资源说明](https://github.com/naptha/tesseract.js/blob/master/docs/local-installation.md)、[设备语音列表接口](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)。

语音修复：提供声音下拉选择、试听、停止、重新读取声音列表和无声帮助；记录各口音的选择。在线声音失败不再直接终止，改为尝试其他可用声音，并显示网络、设备或权限相关错误。检测启动超时，停止或切换后忽略旧回调，保留当前 utterance 引用避免提前回收。单词和整句使用同一播放逻辑。验证运行 `node --test tests/*.test.js` 与 `python tests/speech_browser_qa.py`。真实 Edge 默认声音的播放完成事件及 Windows 本机 Zira 非静音 WAV 已验证，不代表已验证用户扬声器实际音量。
